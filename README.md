# Daily English Reader

매일 영어 기사 한 편을 읽고, 모르는 단어를 누르면 **그 문장에서의 뜻**이 나오고,
저장한 단어는 **간격 반복(FSRS)** 으로 복습하는 개인용 영어 학습 앱입니다.

- 앱 주소: <https://qkqh6898-woohak.github.io/DailyEnglish/> (GitHub Pages를 켠 뒤 열립니다 → [배포](#배포-github-pages))
- 설치가 필요 없는 웹앱(PWA)입니다. 폰·노트북 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.
- API 키도 서버도 없습니다. 기사는 미리 만들어 둔 JSON 파일이고, 단어장과 복습 기록은 **내 기기 안에만** 저장됩니다.

> 계획과 조사 내용은 [plan.md](plan.md), [research.md](research.md)에 있습니다.

## 1. 설치 (홈 화면에 추가)

| 기기 | 방법 |
|---|---|
| **Android (Chrome)** | 주소를 연다 → 오른쪽 위 **⋮** → **홈 화면에 추가**(또는 **앱 설치**) → 홈 화면의 **DE Reader** 아이콘으로 실행 |
| **iPhone (Safari)** | 주소를 연다 → 아래쪽 **공유 버튼** → **홈 화면에 추가** → 홈 화면 아이콘으로 실행 |
| **노트북 (Chrome · Edge)** | 주소를 연다 → 주소창 오른쪽의 **설치 아이콘** → **설치** |

**iPhone은 꼭 홈 화면에 추가해서 쓰세요.** Safari는 설치하지 않은 사이트의 저장 데이터를 오래 안 쓰면 지울 수 있습니다.
어느 기기든 단어장이 쌓이면 가끔 [백업](#5-백업과-기기-옮기기)해 두는 것을 권합니다.

발음 듣기는 Chrome(Android·PC), Edge, Safari에서 됩니다. Firefox Android는 지원하지 않습니다.

## 2. 화면 구성

아래쪽 탭 4개: **📰 오늘 · 📚 단어장 · 🔁 복습 · ⚙️ 설정**

### 📰 오늘
- 오늘의 기사(약 300단어)가 보입니다. 아직 올라오지 않았으면 가장 최근 기사를 보여 줍니다.
- **단어를 누르면** 뜻 창이 뜹니다: 그 문장에서의 뜻, 원형, 예문, 기사 문장, 🔊 발음.
  숙어·구동사는 한 단어만 눌러도 구 전체가 함께 강조되고 구의 뜻이 먼저 나옵니다.
- **☆ 저장**을 누르면 단어장에 들어갑니다. 저장한 단어는 기사에서 점선 밑줄로 보입니다.
- 문단 아래의 **번역 보기**로 한글 번역을 펼치고, **문단 듣기**로 그 문단만 들을 수 있습니다.
- **전체 듣기**: 제목부터 문장 단위로 읽어 주며, 읽는 문장이 강조됩니다. 일시정지·이어 듣기·정지, 속도(0.7~1.3배).
- 아래쪽에 **핵심 표현 5개**, **토익 Part 5**(3문제), **출처**, 이전/다음 글과 **지난 기사**가 있습니다.
- 끝까지 읽으면 "읽음"으로 기록되고 **연속 학습일(🔥)** 이 올라갑니다.

### 📚 단어장
- 검색(단어·뜻), 필터(전체 / 단어 / 구 / 어려운 단어), 정렬(최근 저장순 / 복습 임박순 / 알파벳순)
- 단어를 누르면 상세: 예문, 기사 문장(해당 기사로 이동), 복습 정보, 뜻·예문 수정, 삭제
- **＋ 직접 추가**: 기사에 없던 단어도 넣을 수 있습니다. (띄어쓰기가 있으면 "구"로 저장)

### 🔁 복습
- 오늘 복습할 단어를 한 장씩 보여 줍니다. **뜻 보기** → **다시 / 어려움 / 알맞음 / 쉬움** 중 하나를 고릅니다.
  버튼 아래에 다음 복습까지의 간격(예: `1분 · 6분 · 10분 · 6일`)이 미리 보입니다.
- 방향을 바꿀 수 있습니다: **영 → 한**(단어를 보고 뜻 떠올리기), **한 → 영**(뜻과 빈칸 문장을 보고 단어 떠올리기)
- 방금 한 평가는 **되돌리기**로 취소할 수 있습니다.
- 새 단어는 하루 20개까지만 새로 시작합니다. (설정에서 변경)
- 노트북 단축키: `Space` 뜻 보기 · `1`~`4` 평가 · `Z` 되돌리기

### 📝 퀴즈
- **토익 Part 5**: 기사 문장으로 만든 빈칸 문제 3개. 고르면 바로 정답과 해설, 정답 문장 🔊.
- **오답 노트**: 틀린 문제가 모입니다. 다시 풀어서 맞히면 사라집니다.
- **주간 퀴즈**: 일요일에 열립니다(다음 토요일까지 풀 수 있음). 그 주에 저장한 단어 뜻 고르기 + 그 주에 틀린 Part 5.

### ⚙️ 설정
- 발음: 억양(미국식/영국식), 음성 선택, 기본 속도, 미리 듣기
- 읽기: 글자 크기(3단계), 번역 펼쳐 두기, 화면 테마(시스템/라이트/다크)
- 복습: 하루 새 단어 수, 목표 기억률
- 데이터: 백업 내보내기 / 가져오기 / 전체 삭제
- 앱 정보: 버전, 설치 방법, 업데이트 확인

## 3. 손가락으로 쓰는 법 (터치 제스처)

모든 제스처에는 같은 일을 하는 버튼이 따로 있어서, 노트북(마우스·키보드)에서도 전부 쓸 수 있습니다.

| 화면 | 제스처 | 하는 일 | 같은 일을 하는 버튼·키 |
| --- | --- | --- | --- |
| 기사 | 오른쪽으로 밀기 / 왼쪽으로 밀기 | 이전 글 / 다음 글 | 글 아래 `◀ 이전 글` `다음 글 ▶`, 키보드 `←` `→` |
| 오늘 · 지난 기사 | 맨 위에서 아래로 당기기 | 새 기사·목록 새로 받기 | 지난 기사의 `새로고침` |
| 복습 | 카드 누르기 | 뜻 보기 | `뜻 보기`, `Space` |
| 복습 | 왼쪽으로 밀기 / 오른쪽으로 밀기 | 다시 / 알맞음 | 평가 버튼 4개, `1`~`4` |
| 단어장 | 왼쪽으로 밀기 | 지우기 (아래에 뜨는 `되돌리기`로 복구) | 상세 창의 `단어장에서 지우기` |
| 단어장 | 길게 누르기 | 빠른 메뉴 (발음·자세히·수정·지우기) | 마우스 오른쪽 버튼 |
| 뜻 창·메뉴 | 아래로 끌어내리기 | 닫기 | `✕`, 바깥 누르기, `Esc`, 뒤로 가기 |
| 하단 탭 | 보고 있는 탭 다시 누르기 | 맨 위로 | — |

- **세로 스크롤이 항상 우선**입니다. 위아래로 움직이기 시작하면 좌우 제스처는 동작하지 않습니다.
- 화면 **양쪽 끝(24px)** 에서 시작한 밀기는 건드리지 않습니다. 폰의 "뒤로 가기" 밀기와 겹치지 않게 하기 위해서입니다.
- **뒤로 가기**(Android 버튼, iPhone 가장자리 밀기)는 열려 있는 창부터 닫고, 그다음에 이전 화면으로 갑니다. 이전 화면은 보던 위치 그대로 돌아옵니다.
- 지울 때 "정말 지울까요?"를 묻지 않습니다. 대신 지운 직후 **되돌리기**로 복습 기록까지 그대로 살릴 수 있습니다.
- 탭 사이를 좌우로 밀어 옮기는 기능은 넣지 않았습니다. 기사 넘기기·카드 밀기·단어 지우기와 같은 방향이라 서로 헷갈리기 때문입니다.
- 진동 피드백은 Android에서만 동작하며, 설정 → 읽기 → `진동 피드백`에서 끌 수 있습니다. (iPhone은 웹 앱의 진동을 지원하지 않습니다)

## 5. 백업과 기기 옮기기

단어장·복습 기록은 기기마다 따로 저장됩니다. 폰과 노트북 사이에서 옮기려면:

1. 원래 기기: **설정 → 백업 내보내기** → `DEReader-backup-날짜.json` 파일이 내려받아집니다.
2. 파일을 다른 기기로 보냅니다. (메일, 메신저, 클라우드 등)
3. 새 기기: **설정 → 백업 가져오기** → 파일 선택
   - **합치기**: 지금 데이터에 더합니다. 같은 단어는 더 최근에 바뀐 쪽이 남습니다.
   - **덮어쓰기**: 지금 데이터를 지우고 백업으로 바꿉니다.

백업한 지 14일이 넘으면 오늘 화면에 안내가 뜹니다.

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 🔊를 눌러도 소리가 안 나요 | 기기 음량·무음 모드를 확인하세요. Android는 **설정 → 접근성(또는 일반) → 텍스트 음성 변환**에서 영어 음성이 설치돼 있는지 확인합니다. Firefox Android는 지원하지 않습니다. |
| 발음이 어색해요 | **설정 → 발음 → 음성**에서 다른 음성을 골라 보세요. 음성 품질은 기기마다 다릅니다. |
| 오늘 기사가 안 보여요 | 07:00 전이면 아직 생성 전입니다. **지난 기사 → 새로고침**을 눌러 보세요. 계속 없으면 예약 작업이 실패한 것일 수 있습니다(실패 메일 확인). |
| 고친 내용이 앱에 반영되지 않아요 | 위쪽에 "새 버전이 있어요 [새로고침]"이 뜨면 누르세요. 안 뜨면 **설정 → 업데이트 확인**. |
| 단어장이 사라졌어요 | 브라우저 데이터를 지웠거나(특히 iPhone 미설치 상태) 다른 브라우저로 열었을 수 있습니다. 백업 파일이 있으면 **백업 가져오기**로 복원합니다. |
| 시크릿 모드에서 저장이 안 돼요 | 사생활 보호 모드에서는 저장 공간을 쓸 수 없습니다. 일반 창에서 여세요. |

## 개발 안내

빌드 도구 없이 순수 HTML/CSS/JS(ES Modules)로 되어 있습니다. Node.js 22 이상만 있으면 됩니다.

### 폴더 구조

```
index.html            앱 진입점 (화면은 하나, 주소는 #/today 같은 해시)
manifest.webmanifest  설치 정보 (이름, 아이콘, 색)
sw.js                 서비스 워커 (오프라인 저장, 새 버전 알림)
css/app.css           스타일 (라이트/다크, 모바일 우선)
js/
  main.js             시작, 라우터, 하단 탭, 안내 띠
  schema.js           기사 JSON 형식과 검증 (앱·도구 공용)
  articles.js         기사 목록·파일 불러오기 (오프라인 사본)
  reader.js           기사 화면
  popup.js            단어 뜻 창
  tts.js              발음 (Web Speech API)
  db.js               IndexedDB, 백업/복원
  srs.js              FSRS 래퍼 (간격 반복)
  vocab.js            단어장 화면
  review.js           복습 화면
  gesture.js          터치 제스처 (좌우 밀기, 당겨서 새로고침, 길게 누르기, 진동)
  quiz.js             Part 5 · 오답 노트 · 주간 퀴즈
  archive.js          지난 기사
  settings.js         설정 화면
  prefs.js            설정 값 (기본값·저장)
  pwa.js              설치·서비스 워커 등록
  ui.js               토스트·확인 창·바텀시트 등 공통 부품
  util.js             날짜(KST)·표시 형식
vendor/ts-fsrs.umd.js FSRS 라이브러리 (ts-fsrs 5.4.2, MIT)
articles/             기사 JSON (index.json + 연/월/날짜.json)
tools/                기사 도구 (조립·검증·목록) + 개발 서버
tests/                단위 테스트 + 화면 스모크 테스트
prompts/              예약 작업 프롬프트와 초안 예시
```

### 실행과 테스트

```bash
node tools/serve.mjs
```

위 명령 후 <http://localhost:8080/DailyEnglish/> 를 엽니다. (GitHub Pages와 같은 하위 경로)

```bash
node --test tests/*.test.mjs
```

단위 테스트(기사 검증, 토큰화, FSRS, 날짜 계산, 서비스 워커 목록)입니다.

```bash
node --test tests/smoke.spec.mjs
```

실제 브라우저(Chromium)로 앱을 열어 기사 → 단어 탭 → 저장 → 복습 → 퀴즈 → 백업 → 오프라인 → 새 버전 알림까지 확인합니다.
`playwright` 가 설치되어 있어야 하며, 없으면 건너뜁니다. (`npm install --no-save playwright && npx playwright install chromium`)

| 터치 영역 | 48px 이상 | 모든 버튼·입력칸 (기사 속 단어 글자는 제외) |
| 글자 색 대비 | 4.5:1 이상 | 라이트·다크 모든 화면 |

터치 영역 48px과 색 대비는 화면 스모크 테스트가 매번 화면마다 확인합니다.
Lighthouse로 직접 재려면 개발 서버를 띄운 뒤(gzip 압축을 해서 GitHub Pages와 비슷하게 잽니다) 크롬 개발자도구 → Lighthouse에서
`http://localhost:8080/DailyEnglish/` 를 모바일로 측정합니다.

### 앱 코드를 고친 뒤 꼭 할 일

```bash
node tools/update-sw.mjs
```

`sw.js` 의 캐시 버전과 파일 목록을 다시 씁니다. 이 버전이 바뀌어야 사용자 화면에 "새 버전이 있어요"가 뜹니다.
잊으면 단위 테스트가 실패합니다. (기사만 올릴 때는 필요 없습니다)

### 기사 만들기

```bash
node tools/build-article.mjs 초안.json
```

초안(영어 문단 + 단어 사전)을 기사 JSON으로 조립합니다. 초안 형식은 [prompts/draft-example.json](prompts/draft-example.json)을 보세요.

```bash
node tools/build-index.mjs
```

```bash
node tools/validate.mjs --all
```

목록(`articles/index.json`)을 다시 만들고, 모든 기사를 검증합니다. 틀린 곳은 한국어로 알려 줍니다.

### 배포 (GitHub Pages)

1. 이 코드를 `main` 브랜치에 합칩니다.
2. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
3. 1~2분 뒤 <https://qkqh6898-woohak.github.io/DailyEnglish/> 에서 열립니다.

푸시할 때마다 GitHub Actions가 기사 검증과 테스트를 돌립니다(`.github/workflows/`). 실패하면 GitHub가 메일로 알려 줍니다.

### 개인 정보

- 단어장, 복습·퀴즈 기록, 설정은 브라우저의 IndexedDB에만 저장되고 어디로도 전송되지 않습니다.
- 이 저장소는 공개 저장소입니다. 메일 주소 같은 개인 정보는 커밋하지 않습니다. (테스트가 확인합니다)
